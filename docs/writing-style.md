# Writing rules (ASD-STE100)

We write all documentation in ASD-STE100 Simplified Technical English.
These are the most important rules for this project.

## Words

1. Use the approved words of the STE dictionary when possible.
2. Use one word for one meaning. For example, always use "transaction", not "booking" or "movement".
3. Use technical names (for example "camt.053", "IBAN", "Ready to Assign") without change.
4. Do not use phrasal verbs ("set up" → "prepare", "find out" → "examine").

## Sentences

1. Write a maximum of 20 words in a procedural sentence.
2. Write a maximum of 25 words in a descriptive sentence.
3. Use the active voice.
4. Write one instruction in each sentence.
5. Use the imperative in procedures ("Start the server.").
6. Put a warning or a caution before the related instruction.

## Paragraphs and procedures

1. Write one topic in each paragraph.
2. Write a maximum of 6 sentences in a paragraph.
3. Number the steps of a procedure.
4. Start the title of a procedure with "Procedure:".

## Terms of this project

| Term | Meaning |
| --- | --- |
| Budget account | An account that is part of the budget. |
| Tracking account | An account that shows only the balance (for example pillar 3a). |
| Ready to Assign | Money that has no category yet. |
| Assigned | Money that the user gives to a category for one month. |
| Activity | The sum of the transactions of a category in one month. |
| Available | Money that is available in a category. |
| Transfer | A transaction between two accounts of the same user. |
