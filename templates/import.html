Download the statement from your e-banking as "camt.053" (ISO 20022). Swiss banks (for example PostFinance, UBS, Raiffeisen, ZKB and other cantonal banks) supply this format. The application imports only booked entries. If you import the same transaction again, the application ignores it.

For a credit card, download the transactions as CSV. The file must have the columns "TransactionId", "Date", "Amount", "Currency" and "StateType". The file has no IBAN, thus select the credit card account. A positive amount in the file is a charge to the card (an outflow).
